# ultrasound-clinic-control-system
A simple Python project for managing patients and their ultrasound information.
I made this project to practice the things I've learned in Python, especially dictionaries, JSON, file handling, loops, conditions, and error handling.
What it can do
• Add a patient and save their information
• Store patients based on the date
• Store the patient's name, ultrasound type, and price
• View patient information
• Delete a patient
• Save all changes automatically to a JSON file
• Admin mode for managing the stored data
Technologies
• Python
• JSON
What I learned
While making this project, I got more comfortable with nested dictionaries, reading and writing JSON files, using try/except, and working with data stored in files.
This is one of my first projects where I tried to put several Python concepts together into something that feels like a real application.
Note
This is a learning project, so the code is still simple and can definitely be improved in the future.
